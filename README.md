# L'Ardoise — version HTML/Vite

Cette version conserve le composant JSX original et son rendu, mais ajoute un vrai `index.html` et une structure web exécutable.

## Lancer en local

```bash
npm install
npm run dev
```

## Générer la version statique à mettre en ligne

```bash
npm run build
```

Le dossier `dist/` généré peut être hébergé sur Netlify, Vercel, GitHub Pages ou un hébergement statique classique.
